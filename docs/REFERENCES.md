# Research references and licensing boundaries

The following projects were supplied or considered as implementation/design research during development:

- [FireFrame](https://github.com/dyascj/FireFrame)
- [dumbtv](https://github.com/humblemuzzu/dumbtv)
- [firedtvlauncher](https://github.com/xitami/firedtvlauncher)
- [FTVLaunchX](https://github.com/codefaktor/FTVLaunchX) — accessibility HOME-key research
- [tvOS-Launcher](https://github.com/techgenius1/tvOS-Launcher) — visual reference
- [AerioTV-Android](https://github.com/jonzey231/AerioTV-Android) — visual reference
- [Debrify](https://github.com/varunsalian/debrify) — focus/layout reference

This list is attribution of research context, not a statement that these repositories were bundled, that every reference was fully audited, or that any license has been granted to this project. No third-party repository checkout, SDK binaries or installed app artwork is included here. A complete source-provenance/license review remains necessary before selecting a redistribution license or incorporating external code. Consult each reference's current license at the specific revision being used.
